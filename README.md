# 📖 Bookly Frontend

A modern React application for discovering, reviewing, and managing books using the Bookly REST API.

---

## ✨ Features

- 🔐 User Authentication
- 📚 Browse Books
- ❤️ Favorite Books
- ⭐ Reviews
- 👤 User Profile
- 📱 Responsive Design
- ⚡ Fast UI with React

---

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Vite

## ⚙️ Installation

### Clone the repository

```bash
git clone <repository-url>
cd bookly-frontend
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file.

```env
VITE_API_URL=https://bookly-backend-ly2m.onrender.com
```

### Run the application

```bash
npm run dev
```
